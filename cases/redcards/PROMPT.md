This folder contains the dataset from the "many analysts, one dataset" project (Silberzahn et al., 2018, https://doi.org/10.1177/2515245917747646). README.md describes the variables. The research question is: are soccer referees more likely to give red cards to dark-skin-toned players than to light-skin-toned players?

1. Answer the question as a careful analyst would. Choose an approach and justify it. Write one script (R or Python) that runs from a clean start, and report an odds ratio with a 95% confidence interval.
2. List each analysis decision you made that the question and data did not settle for you.
3. Test how robust your answer is. Before running anything, list 6–10 alternative choices that a reasonable analyst could defend, and say which ones you expect to change the conclusion. Then run all of them, and summarise the estimates in one table and one figure.
4. Only after steps 1–3: download the 29 teams' estimates from https://osf.io/download/fa743/ and show where your estimates fall among them. If you state any result from the paper, say where you got it: a source you opened in this session (give the URL), or your memory of the paper.
5. End with two or three sentences on what you conclude.

Write the results to report.md in this folder.
